# PulseCampaign / 城市灵感现场

原创城市创意活动 H5，展示移动端交互、业务规则、表单状态与完整模拟预约闭环。活动名称、地点、人数与日期均为虚构演示内容，无真实预约、支付或个人资料接口。

从仓库根目录运行：

```bash
npm ci
npm run dev:pulse
npm run build --workspace @chenxi/campaign-h5
npx vitest run apps/campaign-h5/src
```

开发入口为 `http://127.0.0.1:5175/pulse/`。生产使用独立 Vite 构建与 Hash 路由，`BASE_PATH` 可设为 GitHub Pages 仓库子路径。根构建将产物汇总至 `dist/pulse/`。

## 可演示流程

1. 按分类筛选四种虚构体验，打开详情并加入灵感日。
2. 选择 1–3 场、1–3 人；同时检查时段重叠、剩余容量和无效数据。
3. 填写虚构昵称并确认本地演示说明，草稿自动保留。
4. 在确认页打开「模拟服务失败」，观察约 0.9 秒延迟、错误反馈和草稿保留，再关闭开关重试。
5. 生成本地回执，刷新可恢复，复制行程文字可使用剪贴板。
6. 查看预约历史、有效预约数、不同体验数和人次；取消预约会释放本地名额，保留取消记录。

金额固定为免费；没有真实售票接口。示例备注仅保留在草稿，不会写入预约历史。

## 代码边界

- `src/domain.ts`：类型、原创活动目录、时间冲突、累计容量、昵称重复校验与持久化数据恢复。
- `src/store.ts`：Pinia 草稿与记录、延迟 Mock、提交快照与防重复锁、错误恢复。
- `src/views/`：发现、详情、三步预约、回执、历史与 404。
- `src/components/`：可复用活动卡片和纯 CSS 原创几何视觉。
- `src/style.css`：响应式排版、交互反馈、减少动态效果偏好与移动导航。

记录仅在当前浏览器保存，数据不上传。配额是本地演示配额，不具备服务端事务或跨设备、跨标签页并发一致性。手动清除存储会重置记录；损坏记录在恢复时逐项校验，超容量、重复预约与无效记录被过滤。

## 验证

17 个单元/状态测试覆盖容量边界、时间冲突、昵称与同意验证、缓存累计容量恢复、提交锁、失败重试、取消统计和运行时错误恢复。根 `tests/e2e/campaign.spec.ts` 覆盖完整预约闭环与 1440/768/390/320px 浏览器检查。最终生产验收以根 `TEST_REPORT.md` 为准。

独立调试时可运行：

```bash
npx playwright test --config apps/campaign-h5/playwright.local.config.ts
```

若使用系统 Chrome，可设置 `PLAYWRIGHT_CHANNEL=chrome`。该配置使用独立开发服务；根 Playwright 配置才用于聚合生产产物验收。
