## 服务与客户端只读审查

审查了 API 入口、SQLite 状态、商城与活动领域、两类客户端与 store。SQLite 事务处理状态变更；演示库存按访问者隔离；服务端计算金额、约束库存/名额、持有优惠券和校验状态转换。Shop 使用 Bearer 演示身份，H5 使用带域范围的 HttpOnly cookie，域间身份分离。写接口检查 Origin、JSON 和相应请求头；本机服务及同源代理的边界在 [API_CONTRACT.md](../upgrade/API_CONTRACT.md) 中说明。

在已读取路径和回归中没有发现新的阻塞性越权或库存绕过；未进行完整渗透测试、公网 CORS 部署验证、长时间压力或全部跨进程竞态穷举。服务端演示能力不等于真实商业支付系统。

身份丢失后“显式归档 UNKNOWN 并停止恢复”的两类 client 实现已阅读；归档并不撤销服务端操作，也不证明原请求失败。该新增归档 UI 未由本角色独立执行浏览器验收，不能把上述 4 项回归扩大为该 UI 的全覆盖。
