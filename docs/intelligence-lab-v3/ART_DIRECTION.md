# 星域智航 V3 · 原创轨道港美术实现

记录日期：2026-10-12。本文记录渲染器完成五轮实际截图检查后的候选版本；整体验收以同目录视觉审查、浏览器与性能报告为准。

## 视觉意图与素材来源

场景采用“前景工作港口—中景运输网络与模块环站—远景行星”的空间层次。左上留给任务介绍，港口占据左下，主环站位于右中。模型是原创硬表面风格，未使用第三方模型、下载纹理、生成背景图或竞品截图，也不声称复刻任何竞品页面。

实现文件：

- `apps/portfolio/src/components/orbit/assets.ts`：程序化几何、材质、标签和环境。
- `apps/portfolio/src/components/orbit/OrbitScene.vue`：状态投影、灯光、镜头、拾取和资源生命周期。

港口由延伸干船坞、桥楼、栏杆、停靠支架、信标和甲板刻线组成。环站采用不闭合模块环、内外结构环、支撑桁架、散热板、服务辐条、非对称伸缩泊位与中心控制塔。铸造节点使用高低不同的立式罐体，储备节点使用横向罐体；中继节点包含碟形天线与太阳能翼，交汇节点采用三臂结构。两艘载体有船体、驾驶舱、侧舷引擎和可见货舱，使用青色、暖琥珀色区分。

行星是具有深度关系的真实球体网格，灰蓝云气由 GLSL 噪声和纬向流带计算；主光方向形成可辨明暗交界。大气边缘、稀疏星点与极淡雾层同样由程序生成。只有站点标签使用 CanvasTexture 生成中文标牌，不包含外部图片。

## 材质、光照与构图

主体采用金属灰壳、深色散热面、少量铜色结构和细窄导航灯。MeshStandardMaterial 提供粗糙度与金属度差异；暖色方向主光、冷蓝轮廓光和较弱补光保留形体转折。使用 ACES 色调映射，没有 bloom、景深或额外后处理链。

桌面全景使用斜向机位，让前景干船坞大于远端节点，环站有明确倾斜和侧面。构图允许前景装饰结构延伸，但业务站点、货运载体和连接关系仍来自统一世界坐标。

手机不是桌面相机的简单缩小。当场景宽度小于 650px 或比例小于 0.7 时，使用独立视角、视场角、目标点和视口偏移；远景行星另行排列。390px 实图中，港口约在 x90/y375、主环站约在 x260/y310，配合底部横排镜头控件保留主体轮廓。这些是当时 470px 场景高度下的构图参考，不是所有设备的固定坐标承诺。

## 状态与画面的一致性

- 站点位置、航道连通性和方向来自 `OrbitSnapshot`，渲染器不修改业务状态。
- 载体位置由 `nodeId` 或 `transit.elapsed / transit.duration` 得出。平滑仅追随已确认的位置，不凭墙钟时间提前交付货物。
- 高亮路线来自真实 `carrier.route` 航道 ID；关闭航道显示红色，货舱显示实际 cargo。
- 统一相机控制器处理全景、对象近景、载体跟随、工程和策略比较。拖动或滚轮打断平滑运动；`cameraRequest` 支持再次点击同一镜头后恢复该模式。
- 站点、载体、航道使用真实 Raycaster 拾取；HTML 对象列表和二维地图由页面层提供等效操作入口。

## 实际截图迭代

渲染开发过程保留在 `.local/v3/renderer/`，该目录被 Git 忽略。截图来自本机 Chrome 打开 `http://127.0.0.1:5173/#/intelligence`，不是设计稿。

| 轮次 | 实图发现 | 具体修复 |
| --- | --- | --- |
| 1 | 桌面过于均匀明亮、实体像同尺度阵列，下方大块空白；手机两侧裁掉港口与环站 | 放大前景干船坞及倾斜主环，补充散热板、桁架、泊位和异形资源舱；降低曝光和均匀补光；独立识别手机场景 |
| 2 | 手机主体偏小偏低；大块发光顶板削弱金属感；行星仍像迷彩地图 | 调整手机距离和垂直偏移，改细窄导航灯，暗化模块顶板 |
| 3 | 右侧竖排控制条与底部状态条仍挤压手机主体；行星裁切且纹理太硬 | 页面层将手机镜头条改底部横排；渲染层重新安排手机机位，行星改柔和灰蓝云气 |
| 4 | 手机行星进入标题区，港口装饰甲板过低 | 为远景行星设置响应式位置，微调手机俯角；主体与标题、底部控制条分开 |
| 5 | 主体轮廓完整，手机港口和环站可同时识别；行星仍需要更明确昼夜边界 | 最后仅调整行星主光方向，不新增特效，随后冻结渲染器 |

对应文件为 `overview-1440-first.png` 至 `overview-1440-fifth.png`、`overview-390-first.png` 至 `overview-390-fifth.png`。明暗收尾后的候选图为 `overview-1440-final.png` 和 `overview-390-final.png`。页面层后续独立验收截图可以包含装饰文字和控件的进一步整理，应以最终验收附件为准。

## 资源控制与验证边界

同一实体的几何按材质合并。标准档 DPR 上限 1.5、像素预算 160 万；精细档 DPR 上限 2、像素预算 210 万。手机标准档渲染目标为 30Hz。隐藏页面停止 RAF；卸载时断开 ResizeObserver、移除监听、取消 RAF、释放几何/材质/纹理、清理 renderer 并移除 canvas。上下文丢失会向页面层报告，以便切换二维入口。

最终截图采样中，1440×620 canvas 为 892,800 像素，静态全景报告 107 draw calls、64 geometries、3 textures；控制台与 pageerror 收集为 0。该记录只是一个本机开发预览采样，不等同于完整性能报告或真实手机测试。
