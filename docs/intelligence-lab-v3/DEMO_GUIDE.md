# 星域智航：三分钟演示与源码追问

入口：[/#/intelligence](https://callmecx.github.io/chenxi-devlab-2026/#/intelligence)。运行模式为本地算法仿真。发布版本和真实验收结论以同目录验收报告及根目录 STATUS 为准。

## 0:00–0:35：给出目标，开始行动

“目标是向曙光站实际交付三份能源。这里有七个站点、九条容量受限航道和两艘容量不同的载体。点击开始即可执行。”

启动后点“近景”或“跟随”，再回到全景。说明镜头仅投影当前状态；动作由固定仿真步推进，不由动画结束判定。打开世界对象，查看当前货物、能量及预留。

## 0:35–1:15：改变世界，展示失败与恢复

从世界对象中选一条未来航道，关闭它，观察版本增加和路线变化。已经进入该航段的船会安全到下一节点，再重新规划。随后“封闭所有航道”，有限执行后得到不可达；“重新开放所有航道”再重试，保留已装载、已耗能与已交付事实。

讲清这是原生合成世界的图搜索和动作校验，不是实体机器人、视觉训练或实时模型在线。

## 1:15–2:05：暂停，同一时刻比较两个未来

重置并开始，再立刻点“暂停并比较策略”。同一个 Worker 内的两个隔离运行时共享快照、种子、已提交事实及故障时序，分别实算时效和能耗策略。比较实际航线、额外模拟步、能量和等待；不要背固定提升百分比，某些快照结果相同。

采用一种策略后，原任务仍位于暂停时刻；点击继续才真正执行预测中的后续动作。优先级调度是启发式，并不宣称全局最优。

## 2:05–2:40：打开工程透视，解释结果依据

展示真实 read-world、reserve-resource、estimate-route 输入输出、来源和耗时，查看事件序号、世界版本、模拟时钟和唯一动作。完成后导出 JSON，进入历史回放并单步/拖动进度，说明回放没有订单、工具和网络副作用。

## 2:40–3:00：落回业务与工程边界

打开实用任务库，指出商品查询/预算比较/草稿审批，以及活动筛选/名额校验/确认流程。主站、商城和 H5 原入口仍可访问。这里没有公开服务端模型或真实支付；模型能力未启用，AGI 仅作为愿景。

## 简历条目建议

**前端 / 全栈版本：** 独立开发 Vue 3 / TypeScript / Three.js 交互式轨道港实验室，将双载体运输运行时与图形渲染分离；实现库存预留、容量与能量校验、航道干预重规划、同源 Worker 策略比较、严格校验回放，以及手机/二维/减弱动效降级。使用单元与真实浏览器测试核验守恒、不可达、取消、迟到结果和图形资源释放。

**AI 工程版本：** 构建可观测的确定性任务规划与工具执行体验，使用 Dijkstra 和优先级预约调度，在同一快照和故障序列上隔离评估两种策略；通过版本校验、唯一动作、人工确认样例与有界失败保证执行边界，提供源码、事件回放及验收证据。

不改任职时间，不写实现 AGI、不写训练视觉模型、不写实体机器人验证、不写商店上架或商业收益。测试数量及性能数字只从本次最终报告引用。
