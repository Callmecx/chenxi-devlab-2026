## 26 项覆盖边界

| 范围          | 实际断言                                                                                                                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4 个首屏      | 1440×900、1920×1080、390×844、360×800：真实 WebGL Canvas active、主开始按钮完整在首屏且高至少 44px、无横向溢出、0 交付与声音默认关闭。视觉质量另见 [视觉复核](VISUAL_REVIEW.md)，没有用这些数值代替审美判断。 |
| 正常运行      | 两载体分别交付 1/2 份；每条导出事件的库存＋载荷＋交付守恒、库存/预留非负、载重/泊位/航道容量约束、能量不增不负、动作 ID 唯一、事件序号递增。                                                                  |
| 暂停与镜头    | 暂停单步恰好前进一 tick；全景、近景、跟随、工程和二维切换不改 runId、tick、版本或物资；暂停期间自动计时不继续写事件。                                                                                         |
| 在途封路      | 关闭载体已进入的航道立即增加版本并清掉旧路线；已有载体到达下一安全节点，关闭后没有新的进入该边动作，最终绕行真实交付。                                                                                        |
| 有限失败恢复  | 全封路明确 UNREACHABLE，库存仍为 4；重新开放后同 runId 重试完成。sealed/scarce/low-energy 三个预置场景分别明确不可达/库存不足/能量不足，无假交付和负库存。                                                    |
| 预置故障      | detour 的 tick 4 故障真实改变世界版本与航道状态，保留故障记录并完成绕行。                                                                                                                                     |
| Worker 隔离   | 实际创建 Worker，两分支从同一暂停快照计算；采用能耗策略只改策略与版本，物理状态/动作保留原快照，后续从原世界完成。                                                                                            |
| 过期分支      | 比较期间重置关闭 Worker 并生成新 run；旧结果不出现。修改世界后禁止采用旧分支；封路后重算显示真实失败分支，原世界仍暂停、未交付。                                                                              |
| 导入与回放    | 有效导入是只读历史投影，退出恢复新的实时世界；随机 seek 对齐记录快照，导出记录不增不减；篡改负能量的 JSON 拒绝导入。                                                                                          |
| 取消与重置    | 取消释放未装载预留，保留已装载货物和已耗能量；重置生成新身份、清空动作。                                                                                                                                      |
| 降级与键盘    | reduced-motion 默认二维，真实 Enter/Space 可选对象；实际调用 WEBGL_lose_context 后转二维且保留物理状态，仍能完成任务。                                                                                        |
| 旋转与触控    | 390→844×390→360×800 保留身份与暂停事实；继续、单步、重置、对象入口、任务设置实际矩形高至少 44px。                                                                                                             |
| 10 次生命周期 | 同一个 document 内反复 hash 路由进入/退出；每次只一个 Canvas，旧 Canvas 脱离 DOM 且真实 WebGL `isContextLost()` 为 true，新 runId 不重复。未将此测试解释为所有 JS 堆对象或系统显存都已精确回收。              |
| 调度输入      | 改优先级后首个资源预留载体随之改变；改目标增加版本且不改既有物资，交付事件实际指向新目标。                                                                                                                    |
| 镜头恢复      | 保持减弱动效、主动启用 3D；真实鼠标拖动显著改变 Canvas 像素，再按同一全景或跟随恢复原图，runId/tick/delivery 不变。                                                                                           |
| 异步导入取消  | 只在测试中延迟 `File.prototype.text`，实际文件仍经过原读取与校验；旧慢导入不能覆盖 reset、较新导入、returnLive、组件卸载后的用户意图。                                                                        |

未由这些浏览器测试覆盖：真实移动硬件性能、完整屏幕阅读器旅程、公开部署、实际付费模型、服务端空间调度、全局最优证明。本实验是本地确定性仿真，不能把成功通过解释为这些能力已经交付。
