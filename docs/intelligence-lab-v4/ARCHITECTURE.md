# 一个世界，受约束的行动

V4保留V3源码与历史测试，以独立`dominion`契约扩展多资源、多任务和attempt。路径搜索直接复用`orbit/graph.ts`的稳定Dijkstra；新运行时承担资格、预约、动作与事件，Vue和Three.js只能投影快照。旧记录不默默迁移为V4：导入显示明确版本提示。

## 事实与所有权

一个会话有11站、16双向航道、六舰、最多四项活动任务。运输/勘测/维修的资格和容量分别检查。任务由带前置依赖的步骤组成，完成必须有装卸、扫描、资源转移或维修事实。`completed/cancelled`不可恢复；`failed`只能通过显式新attempt继续，保留已经完成的步骤、在途承诺和实际货物。

库存包含可预留部分，预留是库存子集；装载时库存减少、舰载增加，交付进入目标站库存，mission.delivered仅是审计投影。守恒式为“站存＋舰载＋舰燃料＋已消耗＝初始＋有来源的生成”。样本只在合法勘测后产生并记录来源。每个有效事件检查守恒、归属、容量、资格、前置条件与唯一动作。

泊位按“已停泊＋已预约入港＋外部占用”计数，航段双向共享有限容量。进入航段即提交能量消耗和目的泊位预约，用户之后关闭该航段只阻止新进入；已进入者先到安全节点。用户通行权限与设施损坏独立，维修不会解除禁行。取消释放未装载预约，已载货仍由原任务持有，只能停泊后显式归还当前站。

## 路径与调度

V3 Dijkstra接收非负整数成本。时效：120×tick＋EU；能耗：120×EU＋tick；稳健：90×场景风险代价＋8×tick＋4×EU；平衡：3×tick＋3×EU＋8×风险，等价于(tick/8＋EU/8＋risk/3)×24。tick按舰速向上取整。风险是合成场景代价，不是概率。偏好路径若燃料不可行会检查最低能耗可行路径。

调度以任务优先级＋每8次等待增加1级排序，之后按创建时间/稳定ID决胜；航段竞争同样对当前等待进行老化。资格、容量、未预约库存、两段路径与燃料全部满足才提交舰/资源分配。不抢占已承诺动作；当前空闲舰燃料不足而合格舰忙碌时有限等待。它是可解释优先级启发式，不声称全局最优。连续36tick无进展、600tick会话上限、6次attempt、1024命令/8192事件限制均有明确停止原因；历史上限预留最后一次可重演的安全关闭。

## 隔离、回放与异步

四种策略比较从同一暂停快照、种子、未来故障表和事件序号建立本地Worker分支，不接适配器、订单或收费工具。采用只更新将来的策略，不能导入预测终点。generation、源指纹和当前世界共同拒绝迟到返回；指纹用于一致性，不是加密认证。

录制包含标准初始世界、完整命令、完整事件和最终状态。导入先检查纯JSON、结构/大小预算和版本，再在隔离运行时重演全部命令。序号、事件、资源与最终快照必须一致；只排除墙钟和真实工具耗时的非确定性差异。回放再使用原事件记录的耗时，不能把验证耗时当成历史调用。校验通过后冻结索引帧；seek仅投影，不提交业务命令或调用网络。记录证明内部一致性，不认证外部文件的作者或真实性。

可替换模型适配器默认运行测试替身。高层提案经过schema、版本和人工审批，提交仍只有受控`add-mission`命令。工具仅读取本场景、查询资源、估算路径和提出计划。真实调用接口无内置SDK/网络；必须在服务端提供显式授权、provider/model与单次/每日预算，浏览器拒绝启用。预算演示使用内存账本，公网启用前还需持久化与实际部署验收。

## 图形边界

场景和资产位于`components/dominion`，页面按路由懒加载。单一相机拥有者管理总览、跟随、指挥桥、靠港、天体和扫描；相机变化不写世界。粒子、尾焰和作业提示取自实际transit/action。画质只改变图形，不删除业务实体。二维星图、键盘对象列表和减弱动效提供同一任务入口。原商城、H5、企业与实用任务库保留独立运行路径。
