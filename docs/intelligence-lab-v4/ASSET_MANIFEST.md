# V4 原创资产清单

记录日期：2026-10-13。清单描述仓库中的实际实现，不表示生产截图、性能或线上发布已经验收。

资产源码位于 `apps/portfolio/src/components/dominion/assets.ts`，装配、状态投影、光照、镜头及销毁位于同目录 `DominionScene.vue`。本轮新增主体未导入模型、影视素材、图片包或生成式背景。Three.js 提供几何与渲染工具，不是舰船或空间站模型来源。

| 资产          | 实际形体与材质                                                                                               | 业务关联与边界                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| 曙光环港      | 分段压力居住环、轮辐、货运主梁、六个悬臂泊位、散热板、货运塔、独立悬挑观察桥；金属灰、铜色结构与有限青色航标 | 唯一业务站点 `port`，位置取共享 fixture；不是六个新增逻辑站点                                      |
| 维修坞        | 开放式双侧龙骨、横梁、承接面、支撑臂                                                                         | `dock` 的泊位与库存仍由运行时决定                                                                  |
| 资源仓        | 成组压力罐、罐体箍带、支承架、连接管                                                                         | 库存展示取站点资源账本；装饰罐数不冒充实际库存数量                                                 |
| 霜环前哨      | 压力穹顶与侧舱、能源组件；冷色表面                                                                           | `ice` 等霜环区域站点，共享实际容量约束                                                             |
| 中继与科研站  | 接收弧、桁架、阵列；科研站采用分叉舱体轮廓                                                                   | 受损标记来自 `station.damaged`；维修不擅自解除用户禁行                                             |
| 采样区        | 不规则多面岩体与设备节点                                                                                     | 样本发现、生成数量与运输来自任务事件，装饰岩石不提供虚构运营数据                                   |
| 方舟运输舰 ×2 | 开放货架、货舱底架、斜撑、装卸横梁、驾驶舱、四个驱动喷口、底部管路与检修缝                                   | 实际货物数量控制货舱件可见性；空舱保持空；装卸构件只随真实动作进度改变                             |
| 游隼勘测舰 ×2 | 轻型轴向机身、三向传感器/能源翼、前置接收环                                                                  | 扫描效果只在实际 `scan` 动作期间显示，位置/范围随动作目标与进度投影                                |
| 织星维修舰 ×2 | 宽体服务拖船、双工具臂、零件架、双驱动                                                                       | 工具臂姿态、修复连线由 `repair` / `rescue` 的实际进度决定                                          |
| 指挥桥        | 有厚度的地板、顶盖、侧壁、舷窗梁、座椅、三个独立实体控制台                                                   | 与环港共享同一个世界位置；内部在首次进入时建立，不是屏幕边框图                                     |
| 桥内三块仪表  | 程序 CanvasTexture：实际拓扑及航道权限/损伤、所选/活动舰的能量载荷和航段、任务完成数和世界时钟               | 读取同一个 `DominionSnapshot`；只在快照或选择变化时刷新，无随机数值或预设成功进度                  |
| 三主题天体    | 曙光蓝色云带与明暗交界；霜环冷色表面与薄环；赤砂矿物色表面及实例化岩带                                       | 程序着色器与原创固定分布；均为视觉对象，采用压缩艺术尺度，不参与航线约束或真实轨道计算             |
| 航道与状态灯  | 明确端点的实体细线、方向标记、选中反馈                                                                       | 11 站、16 路、6 舰来自共享 fixture；`open` 与 `damaged` 独立投影；业务对象可选择，背景不产生假信息 |
| 背景          | 稀疏程序星点、低强度雾层与天体大气层                                                                         | 不是摄影/生成图片，不增加逻辑实体                                                                  |

材质、标签、几何与仪表贴图由资产工厂保留引用，统一 `dispose()`。同材质静态部件合并几何；岩带使用实例化。标准/高/移动画质保留全部业务实体，仅控制渲染预算。清理正确性仍以生产生命周期检查报告为准，不能只凭源码推断已通过。

字体使用浏览器系统字体回退，未分发商业字库。可选短音由页面 Web Audio 振荡器生成，默认静音；本轮没有导入音乐或采样文件。原始截图、视频和迭代记录保存在忽略目录 `.local/v4/`，审核后再选择公开材料。
