# 星域智航 V4 · 模式与发布边界

状态截点：2026-10-13开发集成阶段。V4源码和下述开发流程已经存在，最终生产验收与公开发布尚未完成。本文不填猜测的提交、CI、Release或公网链接；[根STATUS](../../STATUS.md)是统一进度入口。

## 四条运行路径，不混淆其权限

| 路径                            | 当前实现                                                                         | 状态来源与写权限                                                                 | 不能据此声称                                             |
| ------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 本地规划仿真 `local-simulation` | 默认实际运行，六共享视图投影同一会话；三类六舰、任务依赖、资源账本、故障和四策略 | 浏览器确定性运行时提交受限命令；Worker只计算隔离分支；Three.js和二维地图只显示   | 真实宇航仿真、生产物流运营、真实网络调度、全局最优       |
| 事件记录回放 `history-replay`   | 校验JSON后只读seek/播放，初始帧与事件前缀分开                                    | 导入隔离重演、冻结索引帧；不能借回放提交任务或调用付费工具                       | 任意外部记录经过身份认证，旧V3记录已自动迁移             |
| 规划替身 `test-double`          | 在任务编排中以显式参数生成提案，展示只读工具输入/输出/来源，人工批准或拒绝       | 运行在本地世界之上；目标文字是数据，批准后最多向同一运行时提交一个 `add-mission` | 调用了LLM、理解任意自然语言、多个模型自主协商            |
| 模型辅助规划 `model-assisted`   | 有可替换适配合同及授权、预算、工具、来源校验；真实提供方调用未启用               | 浏览器硬拒绝真实模型模式；只有显式服务端上下文和受控调用者可以进入该接口         | 已部署公网模型服务、真实模型评测通过、真实费用或成本下降 |

其中“规划替身”是适配器测试路径，并非一个新的世界数据来源：执行仍归本地运行时。页面常驻模式显示本地仿真或历史回放，提案区域单独注明“不调用模型”。三类舰船也不等于三个LLM Agent。

## 公网与后端

- V4目标是可公开的静态浏览器作品，但当前V4发布尚待核验。既有站点的公开可访问性不能替代V4的部署证据。
- 当前本地仿真、比较和回放不需要公网后端；“模拟断连”只是本次隔离世界的 `set-connection` 命令。它会安全暂停，重连后需要显式继续，不是证明断开或重连了真实服务。
- 商城/H5的已有本机后端与SQLite不因V4而变成公网服务。V4故障控制不能操作其他访客、商城订单或旧项目。
- 真实模型提供方、模型ID、凭证、费用授权与公网接入尚未提供。当前适配器没有内置供应商SDK或主动网络调用；预算演示为内存账本，不能当作持久化账单系统。
- 不申请VR/XR设备、手机GPU、微信发布或App上架结论。390/360浏览器视口检查不等于手机真机检查。

## 尚待统一验收的事项

根负责人仍需完成当前生产源码的一致构建、全仓类型/Lint/单元/API、V4与既有站点完整浏览器回归、最终六幅视觉检查、性能与资源生命周期、正式完整录屏和公开部署验收。当前文档没有将已写但未运行的用例计入通过数。

素材均由项目代码生成，当前没有下载外部模型或纹理。程序几何、材质和场景构图是原创实现；框架及库仍按各自开源许可使用。源码存在不自动证明视觉已经达到用户要求，最终视觉结论应依据真实画面及用户反馈。

正式发布后应由根负责人在统一状态、测试和部署报告中写入实际提交、运行、附件和匿名浏览器结果，再更新此处当前状态；保留上述开发历史的日期与范围。
