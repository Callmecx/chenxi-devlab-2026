正式采集来自本机生产包，Chrome154.0.8037.94，1440×900高档与390×844移动档、DPR1；开始/结束构建元数据均为同一干净157e5f6，构建时间06:30:42.526Z。采集结果包括14张主画面、11张资源/预约/导入补充画面与一条原始WebM，0浏览器错误、0横向溢出。版本、状态、哈希和条件见[媒体清单](media-manifest.json)。手机为桌面浏览器视口模拟。

开发服务器可能发生 HMR，不能据此给最终成品签收。早期第 1、3 轮中标为 planet 的桌面文件在等待时发生重置、实际返回 overview；这些原文件保留为失败/无效样本。第 4 轮起脚本在等待后再次确认相机及 canvas 身份，不再把文件名当作状态证据。

## 原始录屏与复现

原始 `dominion-guide-original.webm`：**101.640秒**，1440×900、VP9/25fps，32,567,750bytes，SHA256 `381e704c1945ace82eccc04bc234a949b21d71c176bdbbd9ff82a83ffdedcff8`。负责人已查看原片12/30/50/75/98秒处未经编辑的五帧，覆盖执行、维修与实际完成；编码数据由ffprobe实际读取，未经剪辑、加速、补帧或画面编辑；大文件以Release附件交付，不塞入源码Git。

业务完成观测耗时96.914秒，与影片编码时长不同。实际过程经过T11扫描后封路、T38维修后比较、T67/W4两任务交付；最终142事件，禁行边仍open=false而damaged=false。导出的[合成运行样本](guide-example.json)再次由页面“导入执行记录”严格验证，历史滑条到末端与原session/T67/W4/完成2一致。

可复现脚本：`scripts/capture-dominion.mjs`。它通过公开页面按钮和导出 JSON 读取真实状态，不向运行时注入成功结果、不修改 CSS 隐藏问题，也不剪接录像。

```powershell
$env:TEMP = Join-Path (Get-Location) '.local\tmp'
$env:TMP = $env:TEMP
node scripts/capture-dominion.mjs http://127.0.0.1:4173/#/intelligence .local/v4/final-capture
```

正式采集默认拒绝 `sourceTreeDirty: true`；如明确做候选采集，可设置 `CAPTURE_ALLOW_DIRTY=1`，输出将标为候选。`EXPECTED_REVISION` 锁定完整源码 SHA。前后读取 `build-meta.json`，版本、构建时间、basePath 或 dirty 状态变化即判失败。录制使用现有工作区Playwright缓存；不在C盘另装编码器。

## 明确边界

390px 是桌面浏览器视口模拟，不是手机真机或 VR 设备验收。画面表现为原创、压缩尺度的程序化工业科幻场景，不称电影级资产、外部设计认证或真实航天验证。本文件不替代业务 E2E、资源释放、性能、无障碍或线上匿名检查的独立结果。
