# 能力与模式矩阵

核验日期：2026-10-12。模式名称与类型定义对应；类型中预留 `server-model` 不表示已经实现该能力。

| 能力 | 本地算法仿真 | 历史回放 | 真实模型执行 |
| --- | --- | --- | --- |
| 当前可用状态 | 已实现，默认入口 | 已实现，需有效记录 | 未实现、未配置 |
| 目标处理 | 三个预设与结构化规则；不支持的文本需澄清 | 读取当时输入 | 无模型调用 |
| 商品/活动查询 | 版本化原创合成 fixture | 读取已记录输出与来源 | 无实时搜索或检索服务 |
| 计划与比较 | 确定性工作流、预算/数量/库存检查 | 读取历史计划和节点 | 无 LLM 规划 |
| 审批与写入 | 显式批准后下一步执行，一次隔离内存写入 | 无批准入口，不执行写入；可显示历史写入数 | 无模型工具授权链 |
| 仓储 | 真实 A*、容量 1、逐格取送、版本失效和有限重规划 | 读取当时机器人、货物和路径快照 | 无物理设备、训练策略或视觉输入 |
| 故障处理 | 超时/部分结果/失败注入，重试、拒绝、取消、重置 | 只显示当时故障 | 未实现 |
| 证据 | 实际事件、输入/输出、来源、实测墙钟耗时 | 原事件与逐步快照 | 无模型名称、token 或费用记录 |
| 持久化 | 当前运行是内存状态；可显式保存记录到 IndexedDB/JSON | IndexedDB 或用户导入 JSON | 无服务端模型任务持久化 |
| 三维与二维 | 同一领域状态的投影，可降级 | 同一历史快照的投影 | 不适用 |

## 与其他演示模块的边界

实验室商品与活动的“确认”只写入当前 runtime，不创建巷集 Select 服务端订单，也不创建 Pulse 的服务端预约。V2 商城/H5 的 `server-demo` 是独立 SQLite 演示 API 模式，与 `server-model` 不是同一种能力；其权限、幂等、库存和未知结果恢复由各自领域验证。

本地仿真无模型凭据仍可完成全部已列出的交互。查询使用合成数据，仓储使用可重复 seed，场景动作由明确算法计算。没有伪造在线模型响应，也没有把动画、历史记录或固定文案描述成模型推理。

## 当前明确未包含的能力

- 真实 LLM provider、服务端流式模型执行、多模型评估与费用控制。
- 自主理解任意任务、开放互联网操作、无人审批的外部写入。
- 模型训练、强化学习、计算机视觉、摄像头或实体机器人控制。
- 真实交易、付款、商家库存与线下活动履约。
- 跨设备同步实验记录或导入记录的签名认证。

## 验证范围

已有领域测试验证规则、异步边界、A* 与回放安全；真实 Chrome 测试验证商品/活动、仓储、回放、3D 降级与移动布局。测试数量和未覆盖环境见 [EVALUATION_REPORT.md](EVALUATION_REPORT.md)。当前文档不声称真实模型评估、全站性能达标或公网发布完成。
