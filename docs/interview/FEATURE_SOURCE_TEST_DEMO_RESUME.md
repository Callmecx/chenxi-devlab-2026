# 功能、源码、测试、演示与简历表述

整理日期：2026-10-12。适用本轮 V2 业务实现与已发布静态版本。本轮生产资源聚合浏览器测试 64/64（约 3.2 分钟）、单元/API 测试 247/247 通过，网页、微信小程序与 App 资源构建通过。固定种子功能评测 450/450 预期结果，本机 API 样本 350 HTTP 请求、0 失败。本机性能报告已归档，V2 已静态公开并通过匿名线上复验；本表不宣称公网 API、设备或商店已验收。

本轮 18 次 Lighthouse 测量（每组 3 次）的 Performance 中位数：首页手机模拟 89 / 桌面 100、EnterpriseFlow 静态案例手机模拟 95、Lab 默认 2D 手机模拟 95、H5 默认本地入口手机模拟 93、商城默认本地入口手机模拟 90；各组 Accessibility 100、CLS 0。首页手机模拟未达 90 分目标，自动评分不代表完整无障碍验收。[导航报告](../acceptance/LIGHTHOUSE_REPORT.md)。独立显式启用 3D 的 6 组样本，rAF 帧间隔均为 p50 16.7ms / p95 16.8ms，仅为本机 headless 桌面 Chrome 空闲场景，不能推广到手机 GPU 或全场景性能。[3D 样本](../acceptance/scene-performance.json)

仓库的 V2 静态主站、`/shop/`、`/pulse/` 及本轮主站新路由已公开并通过匿名线上复验。下表线上链接是已发布入口，服务流程仍需实际可达的本机 API。真实 API 与 SQLite 仅在本机，公网静态 Pages 不承载该服务。智能实验室是确定性本地执行与记录回放，没有连接真实模型或实体设备。

下列源码与测试均以仓库根目录为起点。测试列给出可以追踪的断言，不将多个批次、旧项目或不同端的结果简单累加。

## 使用规则

简历采用可解释的技术动作与约束，不写未经证明的“高并发”“秒级”“零故障”“性能提升百分比”或“全站 100% 通过”。本轮没有提供真实模型凭据、微信正式 AppID、签名 APK/IPA 或真机/商店验收。编译产物与设备运行必须分开。

本轮聚合结果见 [生产浏览器记录](../testing/playwright-results.json)，450 项有限功能评测见 [评估报告](../intelligence-lab/EVALUATION_REPORT.md)，350 请求的环境与限制见 [API 样本](../acceptance/api-performance.json)，资源构建与未验证设备见 [跨端矩阵](../acceptance/PLATFORM_RELEASE_MATRIX.md)。模块检查另见 [CONTENT_EVIDENCE.md](../upgrade/CONTENT_EVIDENCE.md)。不要将历史项目、不同验证层级或重复运行的数字合并。性能测量按导航、3D 空闲场景与本机 API 分别解读，静态发布与匿名复验已通过，具体版本见部署记录。
