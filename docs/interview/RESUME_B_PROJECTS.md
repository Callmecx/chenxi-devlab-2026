# 简历 B：AI 应用工程方向项目段落

这是可替换项目段落，不是已修改或已投递的完整简历。当前未取得原 A/B 可编辑简历；不补写公司、项目起止时间、付费模型调用量、用户规模或收入。项目采用 AI 协同开发，不虚构独立贡献比例。

面向 AI 应用工程，应强调协议、工具边界、可观察性、审批与恢复。**确定性工作流、真实 SSE 传输、真实模型推理是三件不同的事。** 当前 V2 最终聚合验收与发布尚未完成；没有真实模型服务或实体机器人完成声明。

## 可直接替换：Chenxi Intelligence Lab / 可观察工具执行实验

**项目性质：**个人工程研究与交互作品，AI 协同开发。**技术栈：**TypeScript、Vue 3、Three.js、IndexedDB、Vitest、Playwright。

- 实现商品研究、活动助理与仓储取送三个确定性场景，将结构化目标、计划节点、工具输入输出、数据来源及实际执行耗时组织成可追溯事件；不支持或冲突约束显式要求澄清。
- 用独立 TypeScript 运行引擎管理状态、人工审批、取消和有限重试，隔离并发 step 与过期工具结果；确认写入只发生在批准后的执行步骤，拒绝保持零写入。
- 实现四邻接 A* 与离散仓储状态机，通过世界版本使旧路径失效，并验证碰撞、不可达、载荷限制和缺失货物；Three.js 只投影领域快照，提供等价二维操作与上下文丢失降级。
- 记录输入、种子、事件与逐步快照，校验回放导入的结构、顺序、坐标和资源边界；历史 seek 不重新调用工具，使用单元与浏览器验证超时、拒绝、取消、重规划和回放副作用隔离。

**必须保留的范围：**当前运行来自合成 fixture 与确定性规则，未调用真实 LLM、训练感知模型或连接实体机器人；“server-model”类型预留不等于已接入模型。仓储执行是离散模拟器动作，不是机器人真机控制。最终 V2 发布状态另行核对。

归属仓库：[Callmecx/chenxi-devlab-2026](https://github.com/Callmecx/chenxi-devlab-2026)。线上预期路径为 `/#/intelligence`，V2 发布前使用本机已验证版本演示。

## 可直接替换：AI Agent Workbench / AI 交互与协议工程

**项目性质：**个人 AI 应用作品。**技术范围：**AI 交互界面、Node BFF、HTTP/SSE、TXT/MD 文本处理、词法检索与本地记录。

- 组织会话、流式输出、停止重试与请求记录，通过 Node BFF 和真实 SSE 传输处理增量内容；将 Mock 回答和真实网络协议分别标识。
- 针对 UTF-8/帧拆分、终止事件及截断等流式边界，实现增量解析与明确终态；配合 AbortController 和请求序列隔离，防止停止、切会话或重新生成后的迟到响应覆盖当前界面。
- 实现 TXT/MD 分块、词法检索及受控算术等局部能力，记录来源与限制；不将词法召回包装成向量 RAG，不将规则工具调用包装成已验收的自主 LLM 循环。

**历史依据：**2026-09-20 原验收报告记录单元/集成、浏览器 smoke、类型、Lint 与构建通过；本轮只核对资料，没有重跑原项目。真实付费供应商联调、多租户、公网安全沙盒与 Embedding 检索不在已验证范围。

公开源码：[Callmecx/ai-agent-workbench](https://github.com/Callmecx/ai-agent-workbench)。历史材料定位见 [既有项目证据说明](../research/PROJECT_EVIDENCE.md)。

## 可选补充：工具执行后的业务一致性

适合强调“模型之外的工程能力”的岗位；以下属于 DevLab 的真实本机 API 实验，不宣称模型正在操作商城。

- 以 Fastify / SQLite 构建隔离的模拟订单和活动预约服务，使用共享契约、业务事务与幂等记录维护库存、名额和状态约束。
- 对提交结果不确定的场景保留原键、原请求及恢复身份；通过操作查询和同键重试核对业务结果，阻止身份丢失时把旧请求迁移到新会话。
- 设计服务实际写入后中断响应的浏览器测试，并验证人工拒绝、越权、重复提交与取消等失败分支，区分工具调用返回、业务提交成功和界面渲染完成。

**边界：**公开静态演示不含持久化后端，本机 API 不等于公网部署；无真实支付、企业客户数据或生产流量结论。

## 面试可讲的三个重点

1. 如何把来源、输入、实际输出与事件序号串起来，重放时为何必须禁止工具副作用。
2. 为什么审批不是执行成功，取消要同时控制在途任务与迟到结果，有限重试不能绕过失败前提。
3. 为什么采用可验证的确定性预设来检查工程边界；如果后续接真实模型，仍需独立验证输出结构、工具权限、预算、供应商协议与端到端结果，不能用本轮结果提前背书。

不使用“自主通用 Agent”“自研 AGI”“多模态机器人已落地”“训练大模型”“生产级向量 RAG”等未获得证据的表述。源码、测试与演示定位见 [功能映射](./FEATURE_SOURCE_TEST_DEMO_RESUME.md)，讲述顺序见 [演示指南](./DEMO_GUIDE.md)。
